## 结果口径

- 代表任务关闭千问规划，使用固定规划流程检验真实取数和数据整理；115×31、42 名患者、50 条来源记录等结果不归因于千问单独完成。
- GSE76360 的四类原始标签互斥：33 条客观缓解、9 条病理完全缓解、6 条未达到客观缓解、2 条缺失，因此得到 48 条有效疗效记录。
- 63.36 与 91.75 是同一组未封存审核样例上的版本观察值；仍有 5 个任务需复核，系统暂不允许自动发布，91.75 不是冻结正式成绩。
- 当前代表任务对所有表完成行级来源登记；GSE76360 等已接入原始说明的来源支持中文标准值与数据库原值回查，其他表的关键值仍沿同一规则继续贯通。
- 千问与 DeepSeek 是小样本单因素对照；公开检索结果是模块级对照，不等同于乳腺癌正式成绩。

在项目根目录安装 Python、Matplotlib 和 NumPy 后运行：

```powershell
python scripts\build_chinese_paper_figures.py
```
