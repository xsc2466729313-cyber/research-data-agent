# 05 医学安全规则

## 高风险规则

1. `HER2 IHC = 2+` 不得直接转换为 `HER2 Positive`。
2. `ERBB2 CNA amplification` 不等价于 `HER2 IHC positive`。
3. HER2 IHC、HER2 FISH、ERBB2 CNA 应保留检测维度。
4. 低置信度患者/样本关联不得自动合并。
5. 两个高可信来源存在不可解释冲突时输出 `unresolved`。
6. 无有效 Evidence 的关键字段不得进入正式发布数据。
7. 细胞系 `AUC / IC50 / viability` 不等于患者临床 response。
8. 所有标准化都必须保留原始字段与原始值。

## 可自动修复

- 大小写和确定性药物别名
- 明确 Gene Symbol alias
- 确定性 Schema 拼写
- 完全重复记录

## 需复核

- 患者身份关联
- HER2/ER/PR 语义歧义
- 两个高权威来源冲突
- 无原始证据的推断
