## 证据口径

- `goldset/` 保存本文引用的候选审核卷 Manifest、历史基线和严格千问 LIVE 候选指标；该卷未 sealed，不能当作独立最终成绩。
- `evaluation/` 保存公开模块同条件对照结果；不同模块指标不能相加为项目总分。
- `docs/` 中同时附带当前主链、医学规则、SDTI 公式、数据报告、系统设计和前端说明，便于复核正文表述。

本文讨论的是科研数据查找、整理、追溯和可用性判断，不提供临床诊断或用药建议。
