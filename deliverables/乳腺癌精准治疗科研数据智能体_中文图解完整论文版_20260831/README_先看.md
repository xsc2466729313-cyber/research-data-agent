# 中文图解完整论文版阅读说明

## 最快阅读方式

1. 普通读者可直接双击 `docs/乳腺癌精准治疗科研数据智能体_中文图解完整论文版_20260831.html`，用浏览器阅读。
2. 需要继续编辑时，打开同目录下的 `.md` 原稿。
3. 保持文件夹结构不变，正文中的 15 幅图片即可正常显示。

## 本包包含什么

- 完整 Markdown 论文 1 篇；
- 15 幅正文图片，其中包含 Image2 生成的中文概念总览图、4 幅精确中文机制图、4 幅中文数据结果图和 6 幅网页证据截图；
- 4 幅精确机制图的 SVG 源文件，可继续编辑；
- 中文数据图生成脚本和对应的机器可读评测记录；
- 系统主线、数据报告、设计报告、医学安全规则与冻结指标文档。

## 结果口径提醒

- 代表任务的数据规模来自固定规划流程下的真实数据主链实测，不归因于千问单独完成。
- 63.36 与 91.75 是同一张未封存审核卷上的版本复测结果，用于观察系统整体变化。
- 千问与 DeepSeek 的结果是小样本单因素工程对照；公开检索结果是模块级对照，不等同于乳腺癌正式成绩。

```powershell
python scripts\build_chinese_paper_figures.py
```
