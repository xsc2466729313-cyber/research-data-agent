# v2 中文前端与科研数据导出

当前前端主链为千问科研数据 Agent，不再调用阶段 00 Mock 接口。

## 页面能力

1. 输入中文科研问题；
2. 选择真实数据模式或仅规划模式；
3. 显示千问配置、模型名称和凭据是否落盘；
4. 展示千问解析后的疾病、亚型、基因、药物和结局；
5. 展示函数调用选择的工具、参数、状态和真实记录数；
6. 展示候选数据集和官方来源地址；
7. 展示患者/样本级科研数据宽表；
8. 展示中文字段字典；
9. 展示记录规模、结局匹配、缺失、全表完整率、主表基因变量覆盖、请求要素覆盖、自动清洗、孤立记录和重复患者检查；
10. 可视化展示结局匹配、主字段覆盖、请求要素覆盖、来源审计完整度和真实结局分布；无可评测结局时不显示 0 分；
11. 下载 CSV、Parquet 和包含四个工作表的 Excel。
12. 用点线图展示科研问题、多数据库与主科研数据集的选择关系，并明确连线不代表跨患者拼接。

## 主接口

```text
GET  /api/agent/configuration
POST /api/agent/tasks
GET  /api/agent/tasks/{task_id}
GET  /api/agent/tasks/{task_id}/export/csv
GET  /api/agent/tasks/{task_id}/export/parquet
GET  /api/agent/tasks/{task_id}/export/xlsx
```

前端不会展示虚构的 Precision、Recall 或 SDTI。Gold Set 相关指标仍保留在独立评测 API 中，只有加载冻结真实 Gold Set 后才有值。

## 中文展示原则

- 页面标题、操作、状态、风险和建议使用中文；
- 稳定机器字段名保留 snake_case，旁边显示中文标注；
- 非编号型常见分类值在科研宽表中显示为中文，编号与基因符号保持原始稳定代码；
- `Evidence` 表述为“数据溯源/字段证据”；
- `Repair` 表述为“错误修复”；
- 函数调用等必要技术名词采用“中文 + 英文括注”。

## 数据导出

CSV 与 Parquet 使用稳定机器字段名，方便 Python、R、SPSS、Stata 和科研分析脚本读取。

Excel 包含：

- `科研数据集`
- `字段字典`
- `可科研性报告`
- `数据来源`

因此研究者既可以浏览和分析数据，也可以查看每个变量的中文含义、来源和限制。
