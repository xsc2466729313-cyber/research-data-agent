04 · 解释规则

这些数值能说明什么

问题要素覆盖率

模型抽取结果是否覆盖问题中的疾病、基因、结局和数据域要素。它是规则核对指标，不是人工真值准确率。

结构化完整率

科研问题、疾病、结局、数据域和目标字段是否都返回，反映输出是否可进入后续 Agent 流程。

响应时延

记录真实 API 调用耗时。柱状图使用相对柱高，表格保留毫秒值；不能把速度当作质量分。

正式成绩

Precision、Recall、Faithfulness、Traceability、Repair Accuracy 和 SDTI 需要同一 Gold Set 与固定评价合同，当前统一显示“未评测”。

未连接、失败或未运行的模型保持“待连接 / 失败 / 待运行”，不填 100%，不参与平均值。
