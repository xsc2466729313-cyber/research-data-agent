# 03 对比实验与消融设计

## 一、实验分组原则

**所有对照必须做到：**
- 同一输入任务
- 同一候选数据范围/数据版本
- 同一随机种子（能固定时）
- 同一时间窗口
- 同一评价脚本
- 同一 Evaluation Contract
- 每个实验重复至少 3 次（涉及 LLM 随机性时建议 5 次）
- 报均值±标准差；任务型结果补充 bootstrap 95% CI

## 三、Quality Gate 消融

### 必须做的最小消融

A0 `No-Gate`
- 检索 → 解析 → 整合 → 直接输出

A1 `Source Gate`
- 加来源真实性检查

A2 `Source + Integration Gate`
- 再加 Schema/Entity/Conflict 检查

A3 `Full Quality Gate`
- 再加 Traceability/Evidence/Task-critical gate 与反馈闭环

### 观察指标

1. Critical Error Rate ↓
   最终输出中会改变科研结论或造成错误对象关联的严重错误比例。

2. False Acceptance Rate ↓
   不合格数据被错误 PASS 的比例。

3. Traceability Rate ↑
   可回溯到真实来源的关键事实比例。

4. Unresolved Critical Conflict ↓
   最终结果中未解决关键冲突数/率。

5. Coverage / Auto-Publish Rate
   自动通过的数据比例。这个指标不一定越高越好，要展示与质量之间的权衡。

6. Latency / API Cost ↑
   Quality Gate 带来的代价必须如实展示。

### 推荐主图
“Quality–Coverage Trade-off”：
x = Auto-Publish/Coverage
y = 1 - Critical Error Rate
每个点 = 一种 Gate 配置。
理想系统在右上方。

## 五、多 AI Judge 校准实验

目的：
证明多 AI 是“降低人工标注成本的评审代理”，不是伪 Ground Truth。

### 校准集
人工精标 30–50 个代表性语义判断：
- relevance grade
- evidence support
- outcome/field semantic equivalence
- adaptive rubric semantic item

### 方法
J0：Single Judge
J1：Judge A+B 平均/多数
J2：A+B + disagreement adjudicator C
J3：A+B+C + human only unresolved

### 指标
- Agreement with Human
- Weighted Cohen's κ
- Coverage
- Abstention Rate
- Human Review Rate
- Cost/item

预期展示重点：
在与人工一致性不显著下降的前提下，明显降低 Human Review Rate。

不要声称“AI 完全替代专家”。
