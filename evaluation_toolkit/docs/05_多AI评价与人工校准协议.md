# 05 多 AI 评价与人工校准协议

## 1. 只评价不能程序确定的语义项

禁止交给 AI：
- 样本量
- 缺失率
- 重复数
- URL/accession 是否存在
- Schema 类型合法性
- 单位格式
- patient/sample ID exact relation
- 原始 API exact value

允许交给 AI：
- outcome 语义等价
- 自然语言字段与 ResearchSpec 的语义匹配
- Evidence 是否“充分支持”某个结构化科学事实
- Task-Adaptive rubric 中的语义性条件

## 2. 双评—仲裁

每个 Judge 必须独立，不可读取其他 Judge 的答案。

统一输出：
- score: 0–4 或固定类别
- confidence: 0–1
- evidence_span
- rationale（短）
- abstain: true/false

规则：
- A/B 结论一致且 |scoreA-scoreB| ≤ 1：接受平均/共识
- 否则：Judge C 读取原始材料和 A/B 争议理由后仲裁
- C 低置信或仍冲突：Human Review

## 3. 人工校准

比赛前人工精标 30–50 条，覆盖：
- 正确
- 错误
- 模糊
- 冲突
- 证据不足

不要只抽简单案例。

## 4. 必报指标

Weighted Cohen's κ（若为0–4有序等级）
Agreement with Human
Coverage
Abstention Rate
Human Review Rate
Cost / judged item

目标不是追求 100% AI 覆盖，而是在足够高的一致性下减少人工工作量。
