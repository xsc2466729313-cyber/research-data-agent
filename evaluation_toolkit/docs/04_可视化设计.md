# 04 可视化设计

## 原则

1. **正文不堆雷达图。** 外部 Benchmark 需要精确比较，优先横向柱状图/点图。
2. 同一种指标统一方向：↑ 越高越好，↓ 越低越好。
3. 不同量纲不要硬塞在一张图里。
4. 实测值与论文引用值视觉上严格区分，正式结果最好全部同环境重跑。
5. 每张图回答一个问题，不做“为了漂亮而漂亮”的大杂烩。

视觉重点：
- 外部 Benchmark 使用冷色独立区域，表示“能力证明”
- 真实任务/质量门/反馈闭环使用另一组区域，表示“赛题落地”
- 两个闭环箭头：Quality feedback 回前端处理；Fitness gap 回检索

## 图 7：Quality–Coverage Trade-off

Scatter：
x = Auto-Publish Rate
y = 1 - Critical Error Rate

点：
No Gate / Source Gate / Integration Gate / Full Gate

这张图最适合说明：
Quality Gate 不是“分数越高越好”，而是在覆盖率与风险之间找到更好的 Pareto 位置。

## 图 8：Adaptive Fitness 横向对比

主图推荐箱线图/小提琴图：
x = 模型
y = 20–30 个科研任务的 Fitness Score

同时放一张 Win Rate 条形图。

不要只画 4 维雷达图。
雷达图只适合“一个代表任务”的案例解释：
Relevance / Adequacy / Traceability / Reusability。
