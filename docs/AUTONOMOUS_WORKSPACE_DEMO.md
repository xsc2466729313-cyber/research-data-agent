# 自主研究工作区：5–8 分钟演示脚本

## 演示前

- 按根目录 `AUTONOMOUS_WORKSPACE_IMPLEMENTATION_REPORT.md` 启动后端，打开 `/v31/#/workspace`。原根医学工作台仍保留；不要用未重启的旧后端演示新增 API。
- 确认页面模型配置状态。无 Key 可以演示规则规划；不要说成模型已经调用。若演示图像，连接支持的 Qwen-VL 临时会话。
- 实时来源需网络。缓存只有在已经成功采集并校验后才可使用，页面必须保留“真实缓存回放”标识。
- 本轮验收服务 8891 使用独立本地目录；所有演示记录为真实 Run，含测试期间创建的历史研究。Docker 实机尚未验收。

## 0:00–1:00：一句话开始

输入“我想研究 Ia 型超新星光变曲线”，保持实时公开取数、CfA4 来源、日心红移策略，点击一次“开始研究”。

说明：左侧是研究历史，中间是本次自动执行，右侧是 Brief。阶段来自后端事件，没有连续“下一步”按钮。不要把模型规划建议描述成已执行的研究结论。

## 1:00–2:00：过程和多任务

观察理解、规划、来源、真实取数等记录。可以切换 HER2 研究再切回；切换不会启动新 Run 或终止后台运行。等待超过演示时长时，使用明确标为先前完成的真实历史资产，不说成当前 Run 已完成。

本轮 CfA4 一次实测约 28 秒，HER2 实测约 111 秒；网络、模型和缓存均影响耗时，不保证现场同速。

## 2:00–3:30：真实资产与回查

打开 CSV，展示 5,485 条观测的资产行数及前五条真实记录；点击“溯源”，指出星等与红移来自不同原表。

打开 Metadata：展示真实字段映射、MJD 单位和未知时钟尺度、红移参考系。下载原始 TSV 或 ReadMe；说明保存的是该 Run 归档的原件，不是某个未来变化的网页。

打开 Quality 与 Source Lineage：精确 SN 关联、保留缺失值、原始文件 hash。公开访问不等于允许公开再分发。

## 3:30–4:30：解释与改方向

追问“为什么选择这个来源？”：只追加有依据的说明，不创建新的取数 Run。

追问“换用 KSP 来源，独立研究 SN 2021aefx 的光变曲线”：新 Run、新 Session；原 CfA4 版本不变。KSP 实际 1,056 条独立观测，不声称与 CfA4 做了跨源天体校验；未知红移参考系不猜测。

## 4:30–5:30：医学边界与证据血缘

打开已完成的 HER2 研究：两个独立公开来源表处于待复核状态，不是统一患者主表。说明 IHC/CNA/患者身份规则仍保留。

回到当前 Run 的“数据血缘与证据”模块：展示真实 Evidence Graph 的来源节点、精确关联和标准化数据集，再打开 Source Lineage 查看原始响应、转换步骤和 hash。旧表单工具不再出现在主导航，避免把用户带回多步确认流程。
