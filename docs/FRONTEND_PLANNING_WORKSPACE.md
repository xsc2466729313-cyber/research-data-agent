# Guided Research Planning Workspace

## 定位

新版默认首页服务于“只有一个宽泛研究方向”的用户。界面采用左侧阶段导航、中间一条龙研究向导、右侧研究依据与方案详情的三栏工作台。原有完整科研数据生产页面仅保留为技术详情页，并从默认滚动区域隐藏。

参考页面只用于信息架构与交互密度启发；本项目没有复制其品牌、内容或未公开接口。

## 真实业务链路

1. `POST /api/research/topics`：结构化宽泛 Topic。
2. `POST /api/research/topics/{topic_id}/literature-scan`：检索真实论文并保留 `source_id`、provider 与来源链接。
3. `GET /api/research/topics/{topic_id}/question-candidates`：生成带暂定可行性和论文证据的候选科研问题。
4. `POST /api/research/questions/{candidate_id}/select`：生成 Research Blueprint，包括 Required、Recommended、Optional 字段与指标要求。
5. `POST /api/research/contracts/{contract_id}/source-plan`：输出 DatasetCandidate、字段覆盖、fallback 与 Join Policy。

界面不会把未验证的 seed capability 表述为已采集数据；失败时明确显示错误，不生成替代论文、数据集或成绩。

普通问题会先走“初步检索”路径：系统把常见中文问法转换为可检索关键词，调用同一套 Literature Provider，只展示真实论文、来源链接和检索缺口，不创建 Research Contract 或数据任务。用户点击“进入完整研究规划”后，才继续候选问题、方案和来源覆盖检查；问候和闲聊仍停留在直接回复。

Ia 型光变曲线、乳腺癌/医学和通用科研共用同一套工作台面板、会话历史和结果详情组件。领域只改变数据语义与字段：观测级光变数据不会进入患者级 schema，医学安全规则也不会被通用问题或天文任务绕过。

## 使用方式

- 访问 `http://127.0.0.1:8000/`。
- 首次点击“开始完整规划”时，若尚未连接千问 API，先在提示框中选择“去配置 API”。默认模型为 `Qwen3.8-Max`（`qwen3.8-max`）；连接字段保存在当前浏览器本机，用于后端重启后的自动重建，后端实际会话仍只保存在当前进程临时内存中，最长两小时，不写入项目文件。
- 点击任一示例问题，或输入稍宽泛的研究方向后按 `Ctrl + Enter`。
- 输入“什么是乳腺癌”“为什么天空是蓝色的”这类普通问题时，系统先展示真实文献的初步检索结果；需要形成研究方案时，再点击结果卡片中的“进入完整研究规划”。
- 系统自动采用论文依据最充分的问题，并继续完成研究方案和数据可用性检查；其他研究角度默认折叠，仅在用户想调整时展示。
- 规划完成后点击“开始生成数据集”，系统继续执行采集、标准化、对齐和质量检查，不需要跳转到旧页面。
- 右上角“查看技术详情”仅供需要检查完整过程、质量门和溯源信息的用户使用，并提供明确的“返回研究向导”入口。
- 天文详情沿用工作台的章节导航、状态概览、流程卡片、数据矩阵、来源卡片和下载按钮样式，不再以一整页原始文本展示。领域只影响数据及字段内容，患者与观测 schema 仍相互独立。任务编号、英文日志、引用与 SHA256 默认折叠，展开即可核验；当前选中版本可直接下载 CSV、Excel、来源包与质量报告。
- 技术详情按当前对话和具体任务编号加载，展示该次检索的流程、全部闭环轮次和停止原因；历史任务可从已保存的闭环结果恢复。
- 每次数据检索结果独立保留，切换对话不影响已启动的下载；文件名包含任务编号。主表为零行时显示“数据不足”，仅提供实际存在的来源数据包和质量报告。
- “扩大检索并继续”可补充关键词、GEO accession 或 cBioPortal study ID，将入口预算提高到 20、补查轮次提高到 12，并携带原始对话语境及已有候选数据集。它会启动本对话的新一次检索，保留旧结果，不保证补查后必然满足所有字段。
- 来源数据包包含独立 CSV/JSON 表、来源清单与质量报告；来源表可能属于前临床或字段不完整数据，须按各自适用范围使用。

## 验证

- JavaScript 语法：`node --check frontend/app.js`
- 对话隔离与并发下载：`node --test frontend/tests/planner-sessions.test.cjs`
- 历史任务恢复与来源导出：`pytest backend/tests/test_session_artifacts.py -q`
- 静态连线测试：`pytest backend/tests/test_api.py -q`
- 浏览器验收：Topic → 自动查找论文 → 自动确定研究问题 → 自动形成方案 → 自动检查数据 → 用户确认生成科研数据集；并验证技术详情页可往返。
