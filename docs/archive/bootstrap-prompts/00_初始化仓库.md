# Codex 任务 00：初始化仓库

## 目标
建立项目骨架并使用 Mock 数据跑通端到端链路。

## 必须先读
- `AGENTS.md`
- `docs/`
- `configs/`
- `schemas/`

## 任务
1. 创建 FastAPI 后端。
2. 创建前端应用。
3. 配置 Docker Compose。
4. 基于 `schemas/` 建立 Pydantic Model。
5. 使用 `mock/` 跑通：
   问题输入 → ResearchSpec → CandidateSource → CanonicalDataset → Evidence → QualityReport → 前端结果页。
6. 写自动测试。
7. 创建 README 的启动、测试说明。

## 禁止
- 不接真实医学数据库。
- 不修改冻结 Schema。
- 不生成虚假评测成绩。

## 验收
- `docker compose up` 可启动。
- 后端 health 返回 200。
- 前端可打开。
- 业务 Mock 流程测试通过。
