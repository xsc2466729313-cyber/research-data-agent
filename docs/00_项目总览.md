# 00 项目总览

## 项目名称

乳腺癌精准治疗科研数据智能整合系统

## 核心用户任务

输入科研问题，例如：

> HER2 阳性乳腺癌中 PIK3CA 突变是否与新辅助治疗响应有关？

系统完成：

```text
科研问题理解
→ 数据需求判断
→ 多源数据发现
→ 真实数据获取
→ 表格解析
→ 医学标准化
→ Schema 对齐
→ 多源融合
→ Evidence 绑定
→ 错误检测与修复
→ 最终数据集、来源与质量报告
```

## 核心记忆点

**找得准、找得全、整得真、查得回、改得对。**

## 功能分三层

1. 科研需求与数据发现层
2. 多源数据处理与融合层
3. 质量闭环与科研输出层

## 第一版不追求

- 全医学领域泛化
- 医学影像诊断模型
- WSI 模型训练
- 完整知识图谱
- 自动写论文
