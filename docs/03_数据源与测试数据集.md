# 03 数据源与测试数据集

## 第一版必须支持的数据源

| 数据源 | 核心用途 | 第一版 |
|---|---|---|
| GDC / TCGA-BRCA | 临床、突变、表达、拷贝数 | 必须 |
| GEO | 表达、临床、治疗响应 | 必须 |
| cBioPortal | 癌症队列、临床、基因组 | 必须 |
| AACT / ClinicalTrials.gov | 临床试验多关系表 | 必须 |
| CIViC | Variant–Drug–Disease–Evidence | 必须 |
| DepMap / PRISM / GDSC | 细胞系药敏 | 增强 |

## 重要数据语义边界

患者队列、细胞系、临床试验、知识证据属于不同层级，不允许暴力横向 Join 成同一患者表。

建议逻辑分层：

```text
patient_level
treatment_response
preclinical_drug_response
clinical_trial
evidence
```

跨层通过 `gene / variant / drug / disease / study` 等标准实体关联。
