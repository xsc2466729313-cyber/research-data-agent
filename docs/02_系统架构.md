# 02 系统架构

```mermaid
flowchart LR
    A["第一层：科研需求与数据发现"]
    B["第二层：多源数据处理与融合"]
    C["第三层：质量闭环与科研输出"]
    A -->|"ResearchSpec / SearchPlan / CandidateSource"| B
    B -->|"CanonicalDataset / Evidence / SourceManifest"| C
    C -->|"Dataset / Report / API / Viewer"| D["科研用户"]
```

## 第一层输出

- `research_spec.json`
- `search_plan.json`
- `candidate_sources.csv`

## 第二层输出

- `canonical_dataset.parquet`
- `evidence.jsonl`
- `source_manifest.json`

## 第三层输出

- `final_dataset.csv`
- `final_dataset.parquet`
- `data_dictionary.json`
- `quality_report.json`
- `quality_report.html`
- `repair_log.jsonl`
- REST API
