# 文档入口

当前文档按用途组织：

- `FINAL_DELIVERY_INDEX.md`：当前发布入口、阅读包和验证结果。
- `PROJECT_REPORT.md`：项目正文与证据边界。
- `REVIEWER_STORY.md`：演示与评审讲解稿。
- `CURRENT_MAINLINE.md`：生产主链、接口和评测口径。
- `AGENT_ARCHITECTURE.md`、`AGENT_WORKFLOW_CN.md`：智能体架构与工作流。
- `00_项目总览.md` 至 `09_Codex开发顺序.md`：系统设计、数据源、规则与复现说明。
- `archive/`：历史方案、阶段报告和旧启动提示，仅用于追溯。

项目硬约束见根目录 `AGENTS.md`，首次阅读见 `README_START_HERE.md`。
